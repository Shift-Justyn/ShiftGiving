# Shift Giving - Mobile App

This is a mobile application for the Shift Giving platform to support donations to organization campaigns.

## Setting Up Your Local Environment

1. Install Xcode

## Running the Application Locally

### Ios App

1. Run the API backend locally
2. Run `open -a Simulator`
3. Run `flutter run`

### Android App

1. Run the API backend locally
2. Run `emulator -avd [Emulator Name]`
3. Run `flutter run` in a separate terminal

## Running the Tests Locally

### Ios App

1. Run the API backend locally
2. Run `open -a Simulator`
3. Run `./run_tests.sh`

### Android App

1. Run the API backend locally
2. Run `emulator -avd [Emulator Name]`
3. Run `./run_tests.sh` in a separate terminal
