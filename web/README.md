# Shift Giving - Web App

This is a web application for the Shift Giving platform to support donations to organization campaigns.

## Setting Up Your Local Environment

1. Run `npm install`

## Running the Application Locally

1. Run the API backend locally
2. Run `npm start`
3. Open http://localhost:8080/ in a browser

## Running the Tests Locally

1. Run the API backend locally
2. Run this application locally
3. Run `./run_tests.sh` in a separate terminal
