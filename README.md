# Shift Giving

Shift Giving is a web application and mobile app that supports donations to organization campaigns.

## Overview

- Frontend
    - `web` directory
    - `mobile` directory
- Backend
    - `api` directory

## Running the Application Locally

1. Navigate to the `api` directory
2. Follow the instructions for running the API locally
3. Navigate to the `web` directory
4. Follow the instructions for running the Web application locally
